## Sequencing

1. **Prepare:** complete metadata/schema validation and the non-account fields of the MCP Registry package. This is the selected next action because it creates a reusable, reversible packet without changing product authentication or publishing.
2. **Prove:** only after Mike's exact approval, execute a synthetic-account connection and revocation proof. Do not use a real account or retain note content.
3. **Build candidate:** if Mike selects guided/distributed discovery, specify and design-approve one OAuth read-only authorization slice. Keep Anthropic and OpenAI review evidence separate.
4. **Submit:** a separate Mike approval is required for every registry or directory submission, account login, and publication.
5. **Measure:** report attributed first-time downloads only when Apple provides the aggregate, and first MCP tool use only after its missing server-side coverage is implemented. Separate debug, internal dogfood, external TestFlight, external App Store, and unknown evidence.
