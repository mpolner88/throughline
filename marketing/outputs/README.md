# Marketing outputs

Use this folder for generated draft packs, signal briefs, reviews, publishing packets, and readouts.

Recommended filenames:

- `YYYY-MM-DD-signal-brief.md`
- `YYYY-MM-DD-angle-plan.md`
- `YYYY-MM-DD-draft-pack.md`
- `YYYY-MM-DD-asset-brief.md`
- `YYYY-MM-DD-community-review.md`
- `YYYY-MM-DD-publishing-packet.md`
- `YYYY-MM-DD-performance-readout.md`
- `YYYY-MM-DD-learning-update.md`

Do not treat this folder as the source of truth. Promote earned learnings into `marketing/voice-and-messaging.md` or `docs/launch-marketing.md`.
