# Marketing assets

Use this folder for source briefs and exported assets used in marketing experiments.

Suggested structure:

- `demo-video/` for shot lists, transcripts, and exported clips.
- `screenshots/` for channel-specific crops.
- `diagrams/` for MCP and workflow diagrams.
- `carousels/` for multi-image post sequences.

Every asset should map back to an experiment ID in `marketing/experiments/experiment-ledger.csv`.
