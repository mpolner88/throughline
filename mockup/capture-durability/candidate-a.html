What stays exactly as accepted

  • Home hierarchy, “Today’s plan”, most-important rows, note cards, recorder idle/recording states, wordmark, spacing — untouched. This candidate adds one item class and one truth line.

Likely production mapping (for the eventual handoff, not implementation now)

  • New: durable capture outbox (app-support storage + small state store), capture card view, client capture ID for idempotent retry.
  • Changed: `HomeView.stopAndUploadRecording` decomposes into keep → enqueue → background save; recorder unblocks after keep; `uploadError` banner and “saved” footer retire.
  • Open questions: server idempotency key on `POST /recordings`; a re-process endpoint for stalled structuring; outbox storage cap policy.
